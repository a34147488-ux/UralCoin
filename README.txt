==================
ЗАПУСК
==================


1. Загрузи все файлы в GitHub репозиторий.


2. Подключи репозиторий к Railway.


3. В Railway выбери:

Deploy from GitHub


4. После загрузки сайт должен открываться по ссылке Railway.

==================
ВАЖНО
==================


Сейчас данные хранятся локально в браузере.


Для полноценного запуска нужны:

- сервер Railway
- база данных PostgreSQL
- Telegram Bot API
- таблицы пользователей


После подключения базы:

Будут работать:

✓ настоящие рефералы

✓ общий топ игроков

✓ переводы между людьми

✓ история

✓ сохранение баланса

✓ защита от накрутки
